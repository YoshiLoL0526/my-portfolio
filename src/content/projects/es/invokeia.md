InvokeIA es una plataforma para clínicas que reúne la gestión diaria y la automatización con IA en un mismo producto. Actualmente es mi trabajo principal.

## Módulos

- Agenda y gestión de citas, con disponibilidad por profesional y recordatorios.
- Historia clínica, planes de tratamiento y seguimiento de pacientes.
- Ventas, presupuestos, facturación y cobros.
- Workflows de automatización y motor de reglas.
- Comunicaciones con pacientes por WhatsApp y email.
- Paneles de resultados y reportes de actividad.
- Agentes de IA para atención, captación y seguimiento.
- Visor DICOM para radiografías y tomografías.

## Tecnologías

Next.js y React en la interfaz; Python y FastAPI en el backend; n8n para la automatización; PostgreSQL como base de datos; Docker para el despliegue. La plataforma se integra con WhatsApp Business API y otros servicios de comunicación.

El producto está en producción. El sitio público es invokeia.com; el código y los detalles internos no se publican.
