Home Budget es una app móvil para llevar el presupuesto de casa con varias monedas: gastos, categorías, presupuestos y reportes en una base local.

- Registro de gastos e ingresos por categoría y periodo.
- Soporte multi-moneda y conversión para gastos en distintas divisas.
- Resumen y reportes para ver a dónde se va el dinero.
- React Native + Expo con SQLite local y TypeScript.

Proyecto personal para practicar producto móvil y modelado de datos financieros.
