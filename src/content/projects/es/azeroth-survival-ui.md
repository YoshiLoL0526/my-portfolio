Azeroth Survival UI es un addon para el mod Azeroth Survivors de World of Warcraft 1.12.1. Sustituye el HUD del cliente por una interfaz pensada para runs de supervivencia.

- Marcos de jugador y objetivo, barra de tiempo con próximos jefes y marcos de jefes con debuffs.
- Radar de cuevas y guaridas en el minimapa, escudo, estadísticas y aviso de vida baja.
- Alertas de caché y estados de la run, con SavedVariables para la configuración.
- API propia del mod (`AZS_*`) para leer reloj, fase, jefes, guardianes, hechizos, buffs, debuffs y medidor de daño.
- Lua + XML sobre la API de WoW 1.12.1, con diez módulos y versión 1.7.0.

Es mi incursión en Lua y en la API de addons de WoW, y una forma de llevar la interfaz de un mod hasta el último detalle.
