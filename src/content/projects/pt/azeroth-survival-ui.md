Azeroth Survival UI é um addon para o mod Azeroth Survivors de World of Warcraft 1.12.1. Substitui o HUD do cliente por uma interface pensada para runs de sobrevivência.

- Frames de jogador e alvo, barra de tempo com próximos chefes e frames de chefes com debuffs.
- Radar de cavernas e covis no minimapa, escudo, estatísticas e aviso de vida baixa.
- Alertas de loot e estados da run, com SavedVariables para a configuração.
- API própria do mod (`AZS_*`) para ler relógio, fase, chefes, guardiões, feitiços, buffs, debuffs e medidor de dano.
- Lua + XML sobre a API do WoW 1.12.1, com dez módulos e versão 1.7.0.

É minha incursão em Lua e na API de addons do WoW, e uma forma de levar a interface de um mod até o último detalhe.
