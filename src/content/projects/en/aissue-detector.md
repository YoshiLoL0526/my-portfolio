AIssue Detector is the interface and microservice that turn an issue report into structured data for the right team.

- React conversational chat to describe the issue and attach images.
- FastAPI microservice that classifies category, severity, type and team with GPT-4.1.
- Report confirmation before submission and secure authentication.
- API-key protection and independent frontend/backend deployment.
- Part of the AiFink platform, alongside the RAG knowledge backend.

Client project at Synapse Innovation Lab; no public repository.
