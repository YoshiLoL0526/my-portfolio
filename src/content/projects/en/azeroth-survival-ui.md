Azeroth Survival UI is an addon for the Azeroth Survivors mod on World of Warcraft 1.12.1. It replaces the client HUD with an interface built for survival runs.

- Player and target frames, a timer bar with upcoming bosses and boss frames with debuffs.
- Cave and lair radar on the minimap, shield, stats and a low-health alert.
- Cache and run-state alerts, with SavedVariables for configuration.
- The mod's own `AZS_*` API to read clock, phase, bosses, guardians, spells, buffs, debuffs and damage meter.
- Lua + XML on the WoW 1.12.1 API, with ten modules and version 1.7.0.

My dive into Lua and the WoW addon API, and a way to take a mod's interface down to the last detail.
